How to read the signal

The ratio prioritizes investigation; it does not diagnose the cause.

Each continuing row first passes an exact category-to-total reconciliation in both years. A ratio is calculated only when every endpoint total/category status is R (Reported) or Z (Implied zero); other official status-coded values are retained but withheld from this comparison.

Control rule

Arithmetic can sharpen the review without becoming a correction layer.

Exact identity

Every comparable source row must reconcile the nine mutually exclusive IPEDS categories to total enrollment before a signal is calculated.

Separate authority

This diagnostic reads the same official IPEDS source rows but never substitutes a reconstructed count for EFNRALT.

External evidence still matters

Institution fact books, census reports, and source-status context remain necessary to distinguish reporting changes from substantive enrollment change.
