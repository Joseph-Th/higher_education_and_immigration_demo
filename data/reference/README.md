# External validation reference

`nces_digest_2025_306_10.csv` is a compact transcription of selected rows from **NCES Digest of Education Statistics 2025, Table 306.10**, prepared in March 2026.

Source: https://nces.ed.gov/programs/digest/d25/tables/dt25_306.10.asp

The table reports enrollment in thousands for degree-granting postsecondary institutions in the 50 states and District of Columbia. The selected fields are:

- total fall enrollment;
- total U.S. nonresident enrollment;
- undergraduate U.S. nonresident enrollment; and
- postbaccalaureate/graduate U.S. nonresident enrollment.

The source notes identify data through 2023 as final and 2024 as provisional. Values are published in thousands to one decimal place, so the reference is inherently rounded.

This file is **not** used to generate the analysis. It is used only as an external publication-level consistency check against values independently derived from the currently downloaded IPEDS complete-data files.

Because the Digest was prepared in March 2026 and the project retrieved current IPEDS files in October 2026, small differences in subgroup counts are treated as release-vintage differences and surfaced rather than silently forced to match.
