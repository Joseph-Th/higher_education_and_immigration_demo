# Data Directory

## `raw/ipeds/`

Official NCES/IPEDS source files downloaded by `scripts/fetch_ipeds.py`.

Raw files are not committed to Git. They are reproducible from the official URLs and can be regenerated at any time.

Expected layout:

```text
data/raw/ipeds/
  2015/
    EF2015A/
    EF2015A_Dict/
    HD2015/
    HD2015_Dict/
  ...
  2024/
    EF2024A/
    EF2024A_Dict/
    HD2024/
    HD2024_Dict/
```

## `source_manifest.csv`

Tracked provenance record generated by the download script. It contains the source URL, retrieval timestamp, SHA-256 hash, file size, and extracted files for each archive.

## `schema_audit.csv`

Tracked cross-year schema check generated by `scripts/audit_ipeds_schema.py`. It records the preferred source CSV for each year, verifies the variables needed by the analysis, and confirms the `EFALEVEL` aggregation labels used for total, undergraduate, and graduate enrollment.

## Future directories

- `interim/`: intermediate normalized tables created from raw IPEDS files.
- `processed/`: analysis-ready datasets used by charts and published tables.

Processed data will be committed only when its size and licensing/provenance make that appropriate.
