Accounting controls

Three independent decompositions must return the same state total.

Student level

Undergraduate change + graduate change = state 2019-2024 net change.

Institutional control

Public + private nonprofit + private for-profit changes = the same state net change.

Institution continuity

Continuing change + entered enrollment - exited enrollment = the same state net change.

Concentration

Top-three directional contribution is divided by all gross institution movement aligned with the state's net direction.
