Working pattern

Detect → preserve → review → advance

1. Detect

Run the online release checker separately from the reproducible research build.

2. Preserve

Write the dated availability snapshot instead of relying on an ephemeral console message.

3. Review

When the package is complete, preserve hashes and run schema/methodology checks before interpreting values.

4. Advance

Change the project year only after required files and review gates support the update.
