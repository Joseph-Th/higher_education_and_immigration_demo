Library governance

Metadata is part of source quality

Scope before citation

Each resource records what it measures so similarly named immigration-related populations are not treated as interchangeable.

Update pattern

Annual, periodic, and as-released sources are tracked differently; a stale recurring source is a maintenance issue, not a silent assumption.

Project role

Primary input, methodology, benchmark, monitoring source, and related research product are separated so validation sources cannot become hidden analytical inputs.

Review date

The last-checked field records human source review. Automated URL health checks supplement it but do not update metadata automatically.
