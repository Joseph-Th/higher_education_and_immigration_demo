Implementation boundary

SQL adds a second way to interrogate the data, not a second authority

Canonical inputs

National, state, control, latest-institution, and institution-change CSVs remain the validated analytical outputs.

Ephemeral database

The SQLite database exists only for one build process and is recreated from source on every run.

Read-only query pack

The parser accepts only SELECT/WITH queries and rejects mutation, schema-change, attachment, and PRAGMA statements.

Independent reconciliation

Each query is checked against values calculated separately from the CSV sources before publication.
